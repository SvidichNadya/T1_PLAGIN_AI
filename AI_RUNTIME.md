# Local AI contract

A true semantic assistant requires a local language model. Under the constraint that the workstation cannot download Python, Node, libraries or model files, model weights cannot be obtained at runtime.

Therefore the product has two explicit layers:

1. Deterministic engine — fully local and dependency-free.
2. Local-model adapter — a strict integration boundary for an offline, preinstalled model/runtime.

The adapter must:
- receive only the selected Work Context;
- never perform network requests;
- never execute shell commands;
- never access arbitrary files;
- run in a Web Worker;
- expose one request/response API;
- enforce maximum input/output sizes;
- return source references with semantic conclusions;
- fail closed when the model is unavailable.

The extension must remain fully functional without the model.

An actual model binary is not generated by JavaScript source code. It is a separate binary asset that must be approved and distributed by the corporate software-distribution process.
